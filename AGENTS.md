# Тендер-Радар — правила проекта

Внутренний инструмент: победители закупок 44-ФЗ/223-ФЗ → контакты → отправка КП.
Открывается как Telegram Mini App и в браузере.

## Стек
Laravel 13, PHP 8.4, PostgreSQL 17, Redis 7, Docker (Caddy как веб-сервер с автоматическим https).
Монолит, без микросервисов.

## Порядок работы
- Перед коммитом: `vendor/bin/pint` → `vendor/bin/phpstan analyse` → `php artisan test`.
  Те же проверки выполняет CI (`.github/workflows/ci.yml`) на PostgreSQL.
- Одна задача — один коммит с сообщением на русском: что и почему.
- Первая сущность («Контракт») — эталон: миграция, модель, enum, сервис, политика,
  FormRequest, контроллер, ресурс, фабрика, сидер, тесты. Остальные — по её образцу.

## Код
- `declare(strict_types=1);` в каждом PHP-файле, типы у всех параметров и возвратов.
- Бизнес-логика — в `app/Services`, контроллеры тонкие.
- Зависимости через конструктор, без фасадов в сервисах и без статики.
- Права — политики (`app/Policies`), валидация — FormRequest на каждое поле.
- Деньги — целые копейки (`*_kopecks`, bigint). Не хранить вычисляемое.
- Секреты только в `.env` на сервере.
