# Тендер-Радар — цель и принятые решения

## Зачем
Каждую ночь находить победителей закупок по электромонтажу и слаботочным системам,
собирать контакты победителя и быстро отправлять ему коммерческое предложение
на субподряд. Пользователь — владелец (обрабатывает ответы сам).

## Что ищем
- Законы: **44-ФЗ** и **223-ФЗ** (коммерческие площадки не трогаем — победители там не публикуются).
- Два вида тендеров:
  - **профильные** — электромонтаж, СКС, СКУД, видеонаблюдение, АПС/СОУЭ;
  - **генподряд** — стройка, реконструкция, капремонт, где в документации есть разделы
    ЭОМ/ИОС1, СС/ИОС5, АПС/СОУЭ.
- **«Горячий» тендер** — заказчик обязал победителя привлечь субподрядчиков из СМП
  (ч. 5 ст. 30 44-ФЗ) и в объёме есть наши разделы.
- Регионы: Москва (77), Московская область (50), Марий Эл (12), Татарстан (16), Чувашия (21).
  Позже география расширяется настройкой.
- Контракты от **1 000 000 ₽**.
- Источник: ЕИС (zakupki.gov.ru), сервис getDocsIP по токену. Открытый доступ без токена
  закрыт с 01.01.2025. Регистрация получателя данных (pmd.zakupki.gov.ru) требует
  квалифицированную электронную подпись (проверено 15.11.2026).
  Решение 15.11.2026: заказчик регистрирует ИП и бесплатно получает КЭП в налоговой,
  затем получает токен. Пока подписи нет, экраны и отправка КП делаются на демо-данных.
  Запасной вариант — платный API агрегатора (DaMIA, ofdata/Чекко), если ЕИС не примет подпись.

## Как отправляем КП
- Почта: корпоративный ящик на домене es12.ru (план — `kp@es12.ru` через Яндекс 360),
  лимит писем в день, персональное письмо по конкретному контракту, строка об отписке.
- Мессенджеры: только кнопка «открыть чат с готовым текстом» — автоматическая
  рассылка незнакомым ведёт к блокировке.
- Шаблон письма — `docs/kp-template.md`. Подробное КП прикладывается PDF.

## Интерфейс
- Telegram Mini App (бот **@RadarTendeMBot**) и тот же сайт в обычном браузере:
  **https://tender.es12.ru**. Если Telegram заблокируют, приложение остаётся доступным по ссылке.
- Макет из 5 экранов утверждён 13.11.2026: Тендеры, Карточка тендера, В работе,
  Шаблон КП, Настройки. Макет — артефакт «Тендер-Радар: макет Mini App» в Claude
  (https://claude.ai/artifact/Pp1vSaUpaedE5B2mZj2LS6, доступ только у владельца).

## Инфраструктура
- Хостинг FirstVDS (аккаунт уже был, идентификация пройдена). Новый сервер только под
  приложение, сервер сайта es12.ru не трогаем. Подробности — `docs/server.md`.
- Почему не Timeweb/Reg.ru: Timeweb 3 840 ₽/мес и свободные ресурсы только в Новосибирске;
  Reg.ru 2 116,81 ₽/мес и идентификация через Госуслуги/карту; Beget — кибератака 1–2.11.2026.
  FirstVDS «Разгон» (2 ядра, 4 ГБ, 60 ГБ SSD) — 919 ₽/мес.
- Домен приложения — поддомен `tender.es12.ru` (DNS зоны es12.ru в DNSmanager FirstVDS).
  На технический `*.fvds.ru` Let's Encrypt не выдаёт сертификат — исчерпан общий лимит.
- Код — закрытый репозиторий GitHub `promstroy407/tender-radar`. Сервер сам забирает
  проверенные версии; ключ доступа к GitHub (только чтение) создан на сервере.
- Telegram из московского дата-центра закрыт в обе стороны: исходящие идут через
  отдельный секретный путь пересыльщика `tg.udallenka.ru` (проект `promstroy407/vpn`),
  входящие — режимом опроса (getUpdates) вместо webhook.

## Правила
Правила кода и работы — в `CLAUDE.md`. Журнал по дням — `docs/journal.md`.
Данные (контракты, контакты компаний) в репозиторий не попадают — только на сервер
(персональные данные хранятся в России) и в его ежедневные резервные копии.
