# Тендер-Радар

Внутренний инструмент: каждую ночь находит победителей закупок по 44-ФЗ и 223-ФЗ
(электромонтаж, слаботочные системы, генподряд с разделами ЭОМ/СС/АПС),
собирает контакты победителя и помогает отправить ему коммерческое предложение.

Открывается как Telegram Mini App и как обычный сайт в браузере.

## Документы

- `docs/project.md` — цель и принятые решения
- `docs/journal.md` — журнал работ по дням
- `docs/server.md` — сервер, выкладка, бэкапы, Telegram
- `docs/kp-template.md` — шаблон письма с КП

## Стек

Laravel, PostgreSQL, Redis, Docker. Один монолит.

## Регионы и фильтры по умолчанию

Москва, Московская область, Марий Эл, Татарстан, Чувашия. Контракты от 1 000 000 ₽.

## Правила разработки

- Перед каждым коммитом: автоформат (Pint) → статанализ (Larastan) → тесты. Те же проверки в CI.
- Строгая типизация, логика в сервисах, зависимости через конструктор.
- Права доступа и валидация каждого поля сразу.
- Деньги хранятся в копейках целым числом.
- Секреты только в `.env` на сервере, никогда в репозитории.
